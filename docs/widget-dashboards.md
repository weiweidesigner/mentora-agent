# Widget dashboards

Open the sidebar Widget entry or `?tab=widgets`. A dashboard is a 12-column canvas with a 24px vertical unit and 20px card gaps. Drag a card header to move it, or its lower-right corner to resize. On small screens the cards stack at full width; vertical size and order remain editable. Header arrow keys move cards and resize-handle arrow keys change dimensions. The minus/plus controls adjust width. Colliding cards move down when an edit ends.

The top tabs create, switch, rename, and delete independent dashboards. Browser local storage (`mentora-widget-boards-v1`) saves the selected board, cards, sizes, positions, artifact URLs, and a bounded conversation history. This release does not synchronize dashboards between browsers or accounts. Each browser supports 40 boards and each board 60 cards. Storage errors remain visible. Reloading an unfinished generation leaves a retry state rather than claiming completion.

The catalogue (`app/static/widget-catalog.json`) points to 29 existing `business-chart-recall` native components. Manual addition asks the existing `/api/chat/stream` research executor to obtain real data for the selected component and entered instrument. The composer asks the same executor for independent financial chart artifacts, using project skill routing and schema contracts. No sample market data, alternate renderer, or new financial execution path is introduced. Native artifact controls, source semantics, theme, and language remain inside their frames. The chart timestamp is the underlying artifact's data timestamp; generation is not a live refresh subscription.

Only same-origin generated/share-artifact HTML URLs are accepted. Generated files open through the existing share-artifact route. The existing nginx subpath rewriting supports `/mentora/`. No new backend route or service restart is required. Requests and results stay attached to their originating board while switching tabs; deleting a pending card or board cannot resurrect it when the request completes.

Validation: `node --test tests/widgets.test.mjs tests/day-entry.test.mjs`. Browser checks include real manual AAPL cash-flow generation; conversational NVDA revenue-composition and EPS generation; desktop header dragging; pointer width/height resize; persistence after reload; and mobile layout.
