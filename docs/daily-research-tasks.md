# 我的一天与云端定时任务

首页“我的一天”位于探索案例与灵感广场之间。支持 A 股、港股、美股，盘前机会、盘中监控、收盘回顾，以及股票、ETF、指数、行业、自选列表模板。自选列表需要填写标的，不读取其他用户或服务器账户的持仓。

## 使用

侧边栏“首页 / 定时任务”切换主页与任务工作区。首页“我的一天”仅展示所选市场当前阶段已经生成的结果，右侧下拉切换市场；点击结果卡片进入对应任务及那次成功运行。桌面端在任务侧栏选择、搜索、筛选任务；手机端在任务首页查看列表。点击“设置任务”或侧栏“＋”创建任务。手机端可输入任务描述，依次确认市场、频率与时间后创建，也能打开完整设置面板。填写问句、标的、频率和时间后保存。时间支持所选市场当地时间或北京时间，以及相对开盘/收盘偏移。规则支持每日、每周、每月、指定日期一次、所选交易所交易日，可以指定结束重复的日期。高级设置包含时区、市场、标的、上下文与通知，不提供模型或强度设置。下一次执行时间以市场时区显示。可暂停、立即运行、编辑或删除任务；暂停不取消已经提交的运行。

服务端调用现有 DeepSeek Harness 和项目技能流程。问句可用 `{{date}}`、`{{market}}`、`{{symbols}}`。只进行研究；调度上下文明确禁止交易、账户修改、外部推送等动作。任务结果通知由固定后端渠道处理。

任务持久化在 `outputs/day-tasks/tasks.sqlite3`，由 systemd 运行的服务器后台每十秒调度。用户电脑关机不影响执行。调度采用单进程 OS 锁、SQLite 事务和最多两个分析 worker；重启后明确标记被中断的执行，排队任务继续执行。只补跑三十分钟以内的遗漏，较旧的报告跳过并计算下一次。相同任务在排队/执行时不会再次提交，手动运行间隔至少一分钟。

新结果完整成功后才原子替换首页缓存；失败保留上次结果。任务对话直接展示已保存的内容与图表，报告中的任务名称打开设置，不展示思考过程。底部任务卡片集中显示运行状态、执行安排、运行记录和任务操作，对话顶部不再放置两排工具栏。运行记录选择器可浏览最近二十次运行（另保留最近成功结果），切换历史不调用模型。此前版本已清除的旧答案无法补回，界面会明确提示。首页继续只展示最近成功结果。高级设置中“每次运行时开启新对话”默认开启；关闭后仅将本任务上一成功答案作为上下文供下次对照，并要求重新核验最新数据。

## 身份与日历

沿用现有无登录网站形态，以服务器生成的随机 HttpOnly、SameSite=Strict Cookie 区分访客；API 每次读写校验所属身份，写入要求自定义请求头。不同浏览器的任务不互通，清除 Cookie 后无法找回。正式账户体系可用登录用户 ID 替换 owner 解析，迁移时须验证所有权。

`exchange-calendars` 的 XSHG、XHKG、XNYS 日历处理节假日、午休、提前收盘和美股夏令时。它是版本化的交易日历，并非交易所实时状态源；临时停市和未来节假日应更新依赖/日历。当前版本 XSHG 已公布范围截至 2026 年末；超范围时拒绝交易日调度，绝不退回“周一至周五”的近似规则。发布新年份日历前须更新依赖并验证跨年任务。任务若因日历边界无法计算下一次会显示无下次时间，重新保存后可恢复。

## 通知

- Chrome：在设置点击“开启当前浏览器通知”，授权后注册同源 Service Worker 和 Push API 订阅；保存勾选了浏览器渠道的任务。电脑关闭期间不能弹窗；网络、系统和推送服务影响送达，不保证实时通知。
- 飞书：每个任务填官方群自定义机器人 Webhook；可选签名密钥。
- 企业微信：每个任务填官方群机器人 Webhook。不会自动复用服务器上已有其他群配置。
- 个人微信：Server酱 Turbo 渠道，填写 SCT 开头的 SendKey，并在 Server酱完成微信渠道绑定。只支持 SCT 版本；SC3 的 sctp 密钥暂不支持。消息经过第三方服务，额度按服务商规则。

机器人消息为摘要和带随机访问凭证的“最新结果”链接，可在手机打开。任何持有链接的人都能查看该任务最新结果，勿公开转发；删除任务立即使链接失效。分享链接在新版任务页面中展示结果与只读设置；链接不授予任务写入或历史浏览能力，编辑仍须使用创建任务的浏览器身份。Webhook 与签名密钥用 Fernet 加密存储，从不返回给前端；取消渠道保存时清除，编辑时空白沿用。通知出站只允许官方渠道域名，浏览器订阅也使用域名白名单。失败通知最多重试三次，不会重新运行分析。

## 部署

新增依赖在 requirements.txt，安装后重启 `veya-agent.service` 即可启动调度。默认在 `outputs/day-tasks/` 自动生成数据库、渠道加密密钥和 VAPID 密钥，文件私有权限。必须一起备份和持久保存该目录，不能放入临时容器文件系统，也不能公开静态托管。现有 `/generated` 静态路由与 `outputs/day-tasks` 分离。

环境变量：

- `VEYA_DAY_DATA_DIR`：可选的持久化目录；默认项目 outputs/day-tasks。
- `VEYA_DAY_SCHEDULER=0`：测试或只读副本关闭自动执行；生产默认开启。
- `VEYA_PUBLIC_URL`：消息结果链接的网站入口，默认 https://weiweidesigner.com/veya/。
- `VEYA_PUSH_CONTACT`：VAPID 联系方式，默认网站 URL。
- `AICHART_BASE_PATH=/veya`：现有 nginx 前缀，决定 Service Worker 作用域和通知跳转。

现有 nginx 的 API/静态资源前缀重写已覆盖新入口，无须扩大 Service Worker 到主站。Service Worker 由 `/api/day/service-worker.js` 提供，响应明确限制作用域。部署后检查 API Cookie、私有结果隔离、脚本前缀、Worker MIME/作用域、桌面手机布局和一次完整执行。

任务结果页底部支持继续追问，复用现有 `/api/chat/stream` 接口，携带当前缓存报告和近期对话作为上下文。追问不重跑定时任务、不覆盖原缓存，也不修改任务设置；最近二十条追问消息按任务与运行记录保存在当前浏览器 localStorage，切换记录后分别恢复。分享链接查看者的追问只保存在自己的浏览器。切换任务或离开时中止当前追问，避免回复串入另一条任务。

编辑面板使用自定义频率菜单、时间列表（每15分钟及任意自定义时间）、日历和可搜索IANA时区。频率支持每天、工作日（周一至周五）、交易日（交易所日历）、每周、每月、自定义每周重复日；关闭重复可指定一次执行日期。高级设置仅显示时区。微信和飞书渠道在打开开关后显示SendKey或Webhook及官方说明链接。隐藏的旧配置兼容保留，企业微信在用户重新保存时关闭。任务内容在编辑框中替换模板变量为实际市场、标的和“执行当天”；文本未编辑时提交原模板，编辑后保存用户看到的文字。
