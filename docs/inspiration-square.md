# 首页灵感广场

模块位于原首页案例泳道下方，复用 `.caseCard` 和缓存案例回放，采用自动换行网格。六个 tab 为推荐、市场报告、金融图表、数据分析、金融视频、艺术绘图。推荐展示每类三个精选案例，分类 tab 展示全量案例。

缓存目录：`app/static/cases/inspiration/`。目录内的 `manifest.json` 包含分类标题、副标题与案例索引；每个案例都有 `conversation.json` 和可移植的静态产物。正文和 `provenance` 记录来源、日期、组件、演示状态以及真实执行的 JEV 决策。首页只加载索引，点击卡片才获取对应缓存，无模型推理；“问一问”填入可编辑问句。

| 分类 | 数量 | 来源 |
| --- | ---: | --- |
| 市场报告 | 3 | A 股已核验的一页报告、AMD 历史评级证据、NVDA 缓存现金流，经 StreamViz 编排 |
| 金融图表 | 33 | 与业务组件 schema 一一对应，优先本次真实数据，接口受限时使用非空历史 payload；原生组件负责渲染 |
| 数据分析 | 17 | 全部 16 个通用图表 schema 加通用 OHLCV K线；各例保存实际 JEV 路由结果 |
| 金融视频 | 3 | 项目既有 AInvest 视频检索记录，保留原题、发布时间、封面、来源与观看链接 |
| 艺术绘图 | 3 | 本地 FLUX.2 [klein] 4B，三个固定种子的金融主题原创插画 |

机构交易、基本面评分、关联主题的业务组件使用原生演示 payload，卡片及正文已注明。通用数值图表使用演示数据；研究流程与框架属于方法示意。通用 K线使用 NVDA 已缓存的真实 OHLCV 并复用业务 K线内核。

本次实时视频检索返回空结果，因此使用既有历史视频缓存；没有宣称重新验证原视频的播放状态。部分业务数据接口超时或限流，历史案例正文保留实际快照日期。财报季度沿用数据源财年标签，不能当作自然年季度。

更新时先用对应技能读取 schema、取数并生成非空产物，再更新缓存及索引。禁止只创建有标题、无实际结果的卡片。生成的 HTML 需支持宿主主题，引用公共路径或同目录素材，不能包含本机绝对路径、认证信息或 Cookie。

验证：`node --test tests/cases.test.mjs tests/case-theme.test.mjs`。覆盖分类数量、完整产物、JEV 记录、tab 键盘导航、缓存回放、关闭恢复焦点、演示标注和可移植路径；浏览器额外验证桌面与 390/320px 布局及主题。
