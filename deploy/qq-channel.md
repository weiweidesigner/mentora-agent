# QQ 官方机器人渠道

支持 QQ 单聊和群聊 @ 机器人直接向 Mentora 提问、连续追问，并查询已完成的定时任务结果。
腾讯已停止单聊/群聊主动消息推送，因此此渠道不加入定时通知队列。
普通问题调用原有 Mentora Agent 研究流程；QQ 身份与网页用户隔离，限定只读研究。飞书推送保持原有行为。

## 服务器配置

在部署服务使用的私有环境文件中设置以下变量，然后重启 Mentora 服务：

```dotenv
QQ_BOT_APP_ID=填写机器人AppID
QQ_BOT_APP_SECRET=填写重置后的AppSecret
VEYA_PUBLIC_URL=https://weiweidesigner.com/mentora/
```

不要把真实密钥写进仓库或截图。未配置凭据时回调与连接指令接口返回 503。
密钥轮换后需重启服务，清除旧进程配置。

## QQ 后台配置

1. 在机器人开发设置中选择 Webhook / HTTP 回调接收消息。
2. 代码部署后将回调地址设为 `https://weiweidesigner.com/mentora/api/qq/webhook`。
3. 平台验证回调地址时，服务自动返回 Ed25519 签名。
4. 订阅 `C2C_MESSAGE_CREATE`（单聊）和 `GROUP_AT_MESSAGE_CREATE`（群聊 @）。
5. 在消息 URL 配置中添加 `weiweidesigner.com`，允许回复完整报告链接。
6. 按后台要求配置服务器出口 IP 白名单和测试/沙箱成员，添加机器人开始测试。

后台入口名称以实际界面为准；此实现使用正式 API `https://api.sgroup.qq.com`。
若你的应用仍限定在沙箱 API 环境，需先调整应用使用范围，不能声称已联通。
现有 Nginx `/mentora/` 代理会转发回调和签名请求头，无需额外开放端口。

## 使用

直接发送“今天 A 股市场表现”等问题，无需绑定任务。收到请求后静默调用 Mentora，使用 QQ 专属轻聊天提示词：必要时查询数据，跳过图表、HTML、报告和文件生成，默认回复约 100 至 300 字纯文本。每个机器人、会话及用户独立维护上下文。
“新对话”重置上下文；“最新”或“结果”查看最近一次对话结果；“帮助”查看说明。
同一会话每次执行一个问题，其他会话可并行；重复平台回调不重复执行研究。
群内分析超过回复时限时保存结果，用户再次发“最新”即可获取。
服务重启时已在运行的分析标记中断，未执行的排队问题恢复，已完成回答保留。

定时任务结果仍可绑定：

1. 在自己的定时任务菜单选择“连接 QQ”，复制指令。
2. 私聊机器人发送指令；群内使用时先 @ 机器人再发送。
3. 机器人返回最新成功结果的摘要和完整链接，并记住该任务。
4. 以后发送“任务最新”查询绑定任务；发送“解绑”移除当前绑定。若没有普通对话，“最新”也可查询任务。

每个机器人、QQ 会话和发送者独立绑定一个任务。绑定保存在任务 SQLite 数据库，
服务重启后保留。删除任务会使绑定失效。任务尚未完成时返回等待提示。
分享链接授予读取该任务结果的权限；在群中发送指令和结果会公开给群成员。
定时任务摘要最长 700 字，仍保留其既有结果链接。自由对话不生成分享页面、不附加图表链接，发送层保留 1400 字长度保护；用户需要详细说明时可继续追问。

回调签名使用原始请求体，拒绝缺失签名、篡改或超过五分钟的签名时间戳。
回调按机器人/会话/消息 ID 去重，任务查询回复使用 `msg_seq=1`；普通对话文字回答使用 2、语音使用 3、表情图片使用 4；不发送固定确认回执。
失败回复返回 HTTP 503，允许平台重投；日志不输出密钥、消息内容或分享链接；问题、答案和上下文存储在私有任务数据库。
HTTP 成功但没有消息 ID 也视作失败。网络超时后的送达情况需要在 QQ 中核对。

## Breeze 语音回复

QQ 自由对话由本地 JEV/Laya 按语境选择文字或 Breeze TTS 2 语音，主回答不重复发送。
发送“关闭语音”只收文字，发送“开启语音”允许自动选择语音；偏好按 QQ 用户与会话独立保存。
长回答只朗读前面完整句子（约 140 字），并提示查看文字，避免长语音。

Breeze MLX 8bit 在 Mac 上运行，使用 `scripts/breeze_tts_service.py`，常驻加载模型，
通过 MLX 生成 24 kHz PCM，再由 pilk 编码为腾讯 SILK。
Mac worker 与 SSH 反向隧道由 LaunchAgent 启动并重连：

- 本机只监听 `127.0.0.1:8768`；服务器通过 `127.0.0.1:18768` 访问。
- `/speech` 要求 Bearer 令牌，令牌保存在用户私有文件和服务器私有环境，不能入库。
- 服务配置 `QQ_BREEZE_ENDPOINT=http://127.0.0.1:18768`、`QQ_BREEZE_TOKEN`、`QQ_VOICE_DEFAULT=1`。
- Mac 配置 `BREEZE_MODEL_PATH`、`BREEZE_TOKEN_FILE`，`BREEZE_VOICE` 可调整自然语言音色描述。
- 依赖为 Apple Silicon Python、mlx-audio、FastAPI、uvicorn、pilk；服务器不安装 MLX。

合成后服务器暂存随机 URL 的 SILK 文件，15 分钟后拒绝读取，并在后续合成时清理旧文件。
QQ `/files` 使用 `file_type=3,srv_send_msg=false` 获取资源信息，再通过原消息的
`msg_id` 和 `msg_seq=3` 被动回复语音。不会使用主动发送接口。
Mac 离线、语音失败或超过回复时限均保留已有文字结果，不把语音失败算作分析失败。
语音文件上传依赖腾讯从公网 HTTPS 拉取资源。

Breeze 权重与自部署输出受上游研究和非商业许可约束；具体内容见模型附带 LICENSE。
本机睡眠、关机或断网会使语音不可用，文字仍由云端服务发送。

## 按语境选择表达方式

QQ 不再发送固定的“收到，正在调用 Mentora 分析，请稍候”处理回执。
主回答生成后，复用本地 JEV 命名的决策入口（当前实际模型为 Laya multilingual，
`LAYA_DECISION_URL`），根据用户消息、最近两条上下文和回答内容输出选项概率。
不是通过情绪关键词命中或主模型自报分数判断。

- 语音：模型选择 voice 且置信度不低于 0.72，同时该会话允许语音。
- 文字：正式内容、模型选择 text、低置信度、决策服务不可用、输入超过决策预算，或语音关闭/合成失败。
- 语音成功时不重复发送同一段文字；失败才回退文字。
- 独立判断是否适合额外一张反应表情，add 置信度不低于 0.75 才继续选图；逐图语义匹配分不低于 0.75，且领先次选至少 0.03 才发送。
- 图片只能从内置目录选择，经 QQ 图片富媒体接口被动发送；失败不影响主回复。

模型原始选项、概率、置信度和实际发送方式记录在私有 SQLite 表
`qq_expression_decisions`，聊天中不展示判定过程或分数。概率不是经过校准的心理测量。
“关闭语音”始终优先于自动选择；“开启语音”表示允许按语境选择语音。

内置 12 张蓝发女仆 Q 版“大肥鱼 / DeepSeek 鲸鱼娘”反应图，包含用户提供的一张和社区图库的 11 张。
包含比心、害羞、猫爪卖萌、开心、点赞、摸鱼、晚安、打招呼、干饭、问号、委屈和轻松得意。
图片和语义目录位于 `app/static/assets/qq-fish`，保留原图和水印，不再使用早先错误理解的鱼形角色。
来源、个人使用范围及上游 manifest 见该目录的 NOTICE.md；未将第三方图片声明为项目自有或 CC0。

## 角色定制

网站侧边栏 Trade 下方的「角色定制」（Lucide UserRoundPen，ISC）打开 `?tab=character`。
身份、名称、成年角色年龄、可自定义性格、Agent 提示词、段落长度和表达偏好保存在当前浏览器身份下；页面不展示性别。
「连接到 QQ」填写 AppID / AppSecret，点击「确定并应用」调用腾讯 token 接口验证后，加密保存至 character_qq_connections，并在同一事务中保存页面当前角色设定。
AppSecret 从不回传，留空保存可保持原密钥；每个浏览器身份独立配置，不能覆盖其他身份的机器人。
已接入的默认机器人自动复用现有通道，页面不显示回调地址或绑定指令，下一条消息直接使用当前设定。
仅尚未接入消息通道的新机器人会显示折叠的「首次接入设置」；不能把 token 验证成功误称为已经收到 QQ 回调。
API 返回 ready / requiresWebhookSetup 区分可直接生效与尚待首次接入，AppSecret 不回传。
不要清理浏览器身份 Cookie，否则需要回到原身份管理已保存的连接。旧的一次性绑定 API 保留用于兼容。

表达偏好支持智能、语音、文本、随机；智能沿用本地语境置信度，随机等概率选择文字或语音。
强制语音仍会在合成不可用时回退文字；较长答案发送语音片段时补全全文文字。
年龄、性别和性格作为 Breeze 自然语言音色指导，并不保证复刻某个固定声音。
表情概率 0 关闭、100 每次进入语义筛选；概率提高也适度放宽发送门槛，仍需通过逐图语义匹配。

表情库含十二张内置图片；每个浏览器身份可上传最多三十六张 PNG/JPG/WebP，每张最大 5MB。
上传后统一去除元数据并重编码为最大 1024 像素 PNG，私有文件保存于任务目录 character-stickers。
「添加表情包」打开表情包广场，按合集展示封面、名称、张数和分类，支持搜索、预览、整套添加与移除。
当前八套合集共 90 张，包含大肥鱼、奶蛙（用户原图和 16 张社区图片）、原神、阿库娅与辉夜大小姐；qq-stickers/packs.json 定义合集，catalog.json 定义图片与语义描述。
原来的十二张陪伴日常保留为默认合集，新增合集需用户主动添加；不自动将广场图片全部启用。
已添加合集保存为 stickerPacks，只有已添加合集中符合 stickerIds 设置的图片进入 QQ 语境筛选。
广场添加/移除立即保存，只更新合集和单张兼容筛选，不覆盖页面尚未保存的角色身份字段。
用户上传图片仍归当前身份独立保存，不会自动发布到公共广场。
名称与适用语境描述供本地模型选图；会话仅能使用所属身份的图片和内置图片。
随机不可猜测的图片 URL 供腾讯抓取，元数据列表和删除仅归属身份可访问。

奶蛙来源 Nailong-Studio/NaiWa-Wallpaper，二次元素材来自 ChineseEmoji 社区仓库。
逐图来源说明、原始路径和许可注记随素材保存；GIF 保留原动画。关闭按钮使用 Lucide x 图标（ISC），并支持深浅色主题。

## 同步 QQ 机器人名称与头像

确认连接后使用同一个 AppID/AppSecret 换取的 QQBot token 调用 `GET /users/@me`，读取 username/avatar。
接口文档：https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/users_me.get.html
资料缓存于 character_qq_profiles，不返回 AppSecret 或访问 token；头像仅接受无用户凭据的 HTTPS URL。
每次确认连接强制读取最新资料，已有连接在打开角色页时自动同步（最多五分钟缓存）；读取失败保留已有资料。
QQ 名称用于角色名、预览及后续 QQ 对话身份，名称输入框显示为只读并注明与 QQ 同步。
头像加载失败时使用原默认示意图；身份、性格、提示词和其他偏好仍可编辑。
